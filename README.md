# Spotify Clone / Music Player (Android & Kotlin)

A feature-rich Android mobile application built with **Kotlin**, designed to deliver a smooth music streaming and playlist management experience inspired by Spotify.

## Key Features
- **Audio Playback Management:** Integrated **ExoPlayer** for robust, high-performance audio/video streaming, handling pause, play, and error states gracefully.
- **Modern Android Architecture:** Built using **Jetpack MVVM** architecture (`ViewModel`, `LiveData` / StateFlow) to ensure clean separation of concerns and lifecycle-aware UI updates.
- **Dynamic UI & Navigation:** Implemented modular UI components, fragments, and cards (e.g., `PlaylistFragment`, `AlbumCard`) for an intuitive user experience.
- **Data & Network Layer:** Structured with dedicated database, data models, network services, and repository layers for seamless API communication and local caching.

## Tech Stack
- **Language:** Kotlin
- **Framework & UI:** Android SDK, Jetpack (ViewModel, Fragments), XML / Jetpack Compose components
- **Media Player:** ExoPlayer
- **Architecture Pattern:** MVVM (Model-View-ViewModel)
